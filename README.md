# LeetCode Solutions with Dart 🎯

My solutions to [LeetCode](https://leetcode.com) problems, written in **Dart**.

This repo is a work in progress — I keep solving and uploading new problems.

<br>

## 📌 About

I'm using this repository to practice problem solving and to get more comfortable with Dart's core features.

It also includes some basic Dart exercises that I solved while learning the language (loops, conditions, functions, simple algorithms, etc.).

<br>

## 🧩 What's inside

- **LeetCode problems** solved in Dart, such as Two Sum, Plus One, Move Zeroes, Palindrome Number, Roman to Integer, Single Number, Power of Two, etc.

- **Dart fundamentals practice**: conditions, loops, functions, and simple algorithms like factorial, prime numbers, selection sort, etc.

Topics covered so far include arrays, math, strings, bit manipulation, etc. — and more will be added as I go.

<br>

## 📂 Structure

All solutions live in the root of the repo. Each problem is a single, self-contained `.dart` file named after the problem in snake_case:

```
leetcode_solutions_with_dart/
├── two_sum.dart
├── plus_one.dart
├── move_zeroes.dart
├── palindrome_number.dart
└── ...
```
